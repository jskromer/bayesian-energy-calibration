Raw EnergyPlus Output Files

Direct downloads of the standard eplusout.* output files produced by each simulation run. Open eplustbl.htm in your browser for the human-readable summary report; .eso, .mtr, and .sql are the time-series outputs consumed by post-processing tools (eppy, esoreader, SQL queries, etc.).

File legend: .eso hourly variables · .mtr meters · .sql SQLite database · .eio input echo · .rdd/.mdd available variables/meters · .err warnings & errors · .htm tabular summary report.
